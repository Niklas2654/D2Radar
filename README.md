# Radar

A Destiny 2 companion for Windows: every roll, exact numbers, clears, lowmans, loadouts – plus DIM and Discord one hotkey away.

**[Download the latest version](https://github.com/Niklas2654/D2Radar/releases/latest/download/Radar-setup.exe)** · Windows 10/11

Radar updates itself (Settings → About → Check for updates).

Radar is a fan project and is not affiliated with Bungie. Destiny is a trademark of Bungie, Inc.
